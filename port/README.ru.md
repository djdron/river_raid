# C++ порт River Raid

[English](README.md) | Русский

Вся игра: `river_raid` играет в River Raid так же, как оригинал, — демо-режим, выбор игры, один и два игрока, самолёт, топливо, враги, мосты, очки, жизни, рекорды, пауза и звук. Генератор реки и логика игры дают покадрово то же состояние RAM, что оригинал, отрисовка — тот же экран (см. «Проверка»).

## Сборка
```
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build
```
Ядру и утилитам нужен только компилятор C++17. Игре `river_raid` и просмотрщику `river_view` нужен SDL3: если CMake находит установленный SDL3, он берёт его, иначе при конфигурации скачивает SDL 3.2.24 с GitHub (нужны git и интернет) и линкует статически. Под Linux для сборки SDL из исходников нужны dev-пакеты X11/Wayland (см. `docs/README-linux.md` в SDL). Без них: `cmake -S . -B build -DRR_VIEWER=OFF`.

Под Windows с Visual Studio: `cmake --build build --config Release`, программы появятся в `build\Release\`. Проверено под Linux (gcc); macOS и Windows ещё не проверялись.

## Игра
`river_raid [rom] [-os файл] [-pal] [-seed N]`. ROM ищется в `rom/River_Raid.rom` текущей папки и до трёх папок выше (из репозитория или из `port/build/Release` запускается без аргументов).

После включения над рекой летает демо-режим. START начинает игру; SELECT (или OPTION) выбирает игры 1–8: чётные — для двух игроков (ходят по очереди), игры 3–4, 5–6 и 7–8 начинаются с мостов 5, 20 и 50. Любая клавиша клавиатуры Atari — пауза. После конца игры экран стоит, пока снова не запустится демо-режим (около 35 с).

| Клавиша | Atari |
|---|---|
| стрелки или W A S D | джойстик: влево/вправо — поворот, вверх — быстрее, вниз — медленнее; любое направление выпускает самолёт у моста |
| левый/правый Ctrl, Z, X | огонь |
| F4 или Enter | START |
| F3 | SELECT |
| F2 | OPTION |
| Пробел | клавиша клавиатуры: пауза |
| F11 или Alt+Enter | полный экран |
| Esc | выход |

Клавиатура управляет обоими джойстиками, так что и в игру на двоих можно играть одному. Геймпады: первый — джойстик 1 (и 2, пока второго нет), второй — джойстик 2; крестовина или левый стик, A/B/X/Y или правый курок — огонь, Start = START, Back = SELECT.

## Просмотрщик реки
`river_view [rom] [-os файл] [-pal] [-seed N]` показывает демонстрационный режим оригинала — пролёт над рекой, который игра крутит, пока никто не нажимает START: после включения экран заполняется рекой игры 1, дальше она прокручивается на 1 строку за кадр; корабли и вертолёты просыпаются и плавают, танки едут к мостам и стреляют, вертолёты пускают ракеты (перенесённая логика игры, `src/game.cpp`); внизу панель состояния и бегущая строка с титрами, «Press START key» и радужным логотипом Activision. ROM ищется в `rom/River_Raid.rom` текущей папки и до трёх папок выше, так что из репозитория или из `port/build/Release` он запускается без аргументов.

Буквы и цифры 1–9 берутся из шрифта ОС, которого нет в картридже. В порт встроен шрифт AltirraOS — свободной замены ОС, которая идёт с atari800 (лицензия разрешает копирование и изменение при сохранении копирайта, см. `src/os_font.cpp`); с ней же сняты эталонные трассы. `-os файл` берёт шрифт ОС самой Atari из образа ROM ОС (10 КБ или 16 КБ) или из файла шрифта на 1 КБ.

| Клавиша | Действие |
|---|---|
| Пробел | пауза |
| Вверх / Вниз | быстрее / медленнее, через остановку до полёта назад (от x1/4 до x16 в обе стороны) |
| колесо мыши, PgUp / PgDn | прокрутка по реке вручную, на экран |
| Backspace | вернуться к самой новой строке, обычная скорость |
| B / Shift+B | следующий / предыдущий мост |
| Home | начать заново |
| F1 / F2 / F3 | проверка звука: взрыв / выстрел / звук очков через звуковой драйвер игры (сам демо-режим беззвучен, как в оригинале) |
| F | полный экран |
| Esc | выход |

Сравнение с экранами оригинала (демо-режим, кадры 1000–2300, со значениями RANDOM из оригинала): область реки и панель совпадают попиксельно, бегущая строка тоже, кроме крайних столбцов (левее 24 и правее 359), где эмулятор по-своему обрабатывает плавную прокрутку у края.

Какой объект когда просыпается, решает регистр RANDOM микросхемы POKEY — аппаратный счётчик, который читается в момент, зависящий от таймингов всей машины. Порт моделирует этот счётчик (`src/pokey_random.h`) и запускает его от часов, как настоящая машина запускает его при включении, поэтому каждый запуск свой, как и на настоящей машине; `-seed N` повторяет запуск.

## Как устроен генератор
Каждый вызов `nextLine()` выдаёт новую верхнюю строку экрана:
1. `structureAndWidth`: счёт строк (блок — 32 строки, участок — 2 блока, до моста — 16 участков), шаг LFSR, новая целевая ширина в начале участка;
2. `smoothIsland`: остров и ширина воды плавно идут к цели;
3. `moveBank`: случайное блуждание берега;
4. `startDecoration`: дом или гора на берегу;
5. `drawLine`: 48 байт строки (заливки, куски кромки из таблицы `$B800`, строка декорации);
6. `scrollObjects` / `placeObject`: слоты объектов сдвигаются, каждые 16 строк ставится новый объект.

От игрока и от `RANDOM` генерация не зависит. Это проверено на эталоне: разные сиды POKEY и прогон бота против полёта без управления дают одинаковое состояние на всех строках.

## Проверка
- От состояния из эталона: 119 758 строк всей реки (120 000 кадров), расхождений в состоянии и в растровых строках 0.
- С нуля (`startGame(1)` без эмулятора): после 165 строк заполнения экрана состояние совпадает с оригиналом, затем 29 757 строк без расхождений.
- Игра бота со взрывами мостов и миганием: расхождения только в кадрах возрождения. Их делает код рестарта, он пока не перенесён.
- Проверка ловит внесённые ошибки: каждая из четырёх намеренных поломок (условие блуждания, ширина воды, отрисовка, цвет заливки) дала расхождения.

```
oracle/rr_oracle rom/River_Raid.rom oracle/scripts/ghost_film.txt 30001 out -ghost -ram 0:30000
port/build/terrain_check rom/River_Raid.rom out/ram.bin 0 240 29760 5 -fresh 1 145
```

Отрисовка: в каждом кадре, где в строку экрана 20 входит новая строка, строка оригинала сравнивается с `drawScreenLine()` для строки из генератора на C++ (запущенного с нуля).
- Объекты там, где их поставил генератор: 96,8% строк совпадают за 29 000 кадров (95,3% за 120 000). Остальные отличаются там, где игра сдвинула объект.
- Положения объектов из идущей игры (`-ram`: x, флаги, вид слота): совпадают 98,1%; все оставшиеся строки отличаются только пока активен танк на дороге (`$38`), его рисует логика игры. Необъяснённых строк из 29 600 — 0.

```
oracle/rr_oracle rom/River_Raid.rom oracle/scripts/ghost_film.txt 30001 out -ghost -strip 20 -ram 0:30000
port/build/render_check rom/River_Raid.rom out/strip.bin out/frames.csv -ram out/ram.bin
```
Панель и бегущая строка: наборы символов, собранные из шрифта ОС и картриджа, равны RAM оригинала, состояние прокрутки ($3FB3/$26/$27) совпадает в каждом кадре, а нарисованные строки 180–239 совпадают во всех 1299 кадрах, кроме крайних столбцов бегущей строки (см. «Просмотрщик реки»).

```
oracle/rr_oracle rom/River_Raid.rom oracle/scripts/attract_idle.txt 2300 out -screens 1000:2299 -ram 1000:2299
port/build/status_check rom/River_Raid.rom out/screens.bin out/ram.bin
```
Кадр игры в демо-режиме (`game_check`): от состояния после включения (`Game::startAttract`), со значениями RANDOM из оригинала, порт проходит 19 900 кадров (до моста 20) без единого отличия от RAM оригинала ни в одном сравниваемом байте: состояние генератора, слоты объектов (позиция, направление, вид, бит столкновения), танк, его снаряд, ракета вертолёта, результаты столкновений, память спрайтов, строки реки на экране. Нарисованная по нему область реки совпадает с экранами оригинала во всех 1299 сравненных кадрах.

```
oracle/rr_oracle rom/River_Raid.rom oracle/scripts/attract_idle.txt 20000 out -strip 20
port/build/game_check rom/River_Raid.rom out/ram.bin out/random.log 38 19900 -attract
```

Игра с игроком (`game_check` на прогонах с вводом). От состояния демо-режима порт получает ввод и значения RANDOM оригинала и дальше идёт сам, без перезагрузок; в каждом кадре его RAM сравнивается с RAM оригинала (генератор, слоты, самолёт, топливо, пуля, столкновения, очки, жизни, оба игрока, рекорды и их проверочные байты, панель, бегущая строка, память спрайтов, строки экрана):
- игра бота на одного (`start_only.txt -bot -seed 3`, 8 950 кадров: демо-режим, START, 4 самолёта, мосты, гибели и рестарты, конец игры, снова демо-режим): совпадает, кроме 2 кадров;
- игра на двоих с SELECT и клавишей паузы (`two_players.txt`, до конца игры на кадре 3 007): совпадает, кроме 1 кадра;
- область реки, нарисованная портом (самолёт, пуля, враги, взрывы, танк, снаряды), совпадает с экранами оригинала во всех 1 565 сравненных кадрах игры бота.

Оставшиеся отличия — моменты, где результат оригинала зависит от числа тактов процессора в кадре, а порт такты не считает:
- кадр после старта игры, когда река заполняется по 2 строки за кадр: оригинал дописывает вторую строку уже после конца кадра (снимок RAM видит её кадром позже; на экране ничего);
- пуля касается объекта только на той строке, где DLI читает регистр столкновений: у оригинала это засчитывается, если луч уже прошёл это место (1 кадр из 8 950);
- конец игры: проверка рекорда заканчивается около обратного хода, поэтому оригинал ставит счётчик кадров в $FF прямо перед VBI, сразу после него или кадром позже — смотря какие объекты на экране. Порт делает это перед VBI; дальше счётчик кадров может отличаться на единицу, и демо-режим сдвигается на кадр.

```
oracle/rr_oracle rom/River_Raid.rom oracle/scripts/start_only.txt 9000 out -bot -seed 3
port/build/game_check rom/River_Raid.rom out/ram.bin out/random.log 38 8950 -attract
```

Звук. Звуковой драйвер (VBI B2A5–B3D8, `Game::soundDriver`) прогнан на RAM, которая была у оригинала в начале каждого VBI в игре бота (2989 кадров, из них 2199 со звуком: мотор, предупреждение о топливе, взрывы, выстрелы, очки, снаряд танка): все значения AUDF/AUDC совпали с тем, что записал оригинал. Модель POKEY (`src/pokey_sound.cpp`) сравнена со звуком atari800 на тех же записях в регистры: та же громкость во времени (корреляция огибающих 0,95), те же чистые тоны на той же высоте, шум с той же формой спектра (косинус сглаженных спектров 0,94); посэмпловый рисунок шума отличается — он зависит от того, где окажутся шумовые счётчики.

```
oracle/rr_oracle rom/River_Raid.rom oracle/scripts/start_only.txt 3000 out -bot -wav -vbi
port/build/sound_check rom/River_Raid.rom out/vbi.bin out/pokey.log out/random.log
port/build/sound_render out/pokey.log port.wav
```
