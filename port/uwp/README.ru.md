# River Raid на Xbox (UWP)

[English](README.md) | Русский | [Українська](README.uk.md) | [Deutsch](README.de.md) | [Polski](README.pl.md) | [Italiano](README.it.md) | [Español](README.es.md) | [中文](README.zh.md) | [日本語](README.ja.md)

Игра (без просмотрщика) как приложение UWP: работает на Windows 10/11 и на Xbox One или Series в Dev Mode. Собирается на SDL2, так как SDL3 больше не поддерживает UWP. **Ещё не проверялось**: написано без Windows под рукой; если какой-то шаг работает не так, как описано, напишите, что произошло.

## Что нужно
- Windows 10/11 и Visual Studio 2022 с нагрузками «Разработка классических приложений на C++» и «Разработка приложений для универсальной платформы Windows» (с инструментами C++ для UWP, v143).
- CMake 3.16 или новее (подойдёт тот, что в Visual Studio) и git: SDL2 скачивается и собирается вместе с игрой.
- Для Xbox: аккаунт разработчика и консоль в Dev Mode (приложение «Dev Mode Activation» на Xbox).
- Ваш дамп картриджа как `rom/River_Raid.rom` (8192 байта): он кладётся **в пакет**, так что пакет только для вас; не раздавайте его.

## Сборка
```
cmake -S port -B build-uwp -G "Visual Studio 17 2022" -A x64 -DCMAKE_SYSTEM_NAME=WindowsStore -DCMAKE_SYSTEM_VERSION=10.0
```
Откройте `build-uwp/river_raid_port.sln`, выберите Release и x64 и сделайте `river_raid` запускаемым проектом. Сначала запустите на локальной машине (Windows): в окне должна появиться игра.

Пакет подписывается тестовым сертификатом, который идёт с CMake (`CN=CMake Test Cert`). Свой: `-DRR_UWP_CERTIFICATE=my.pfx -DRR_UWP_PUBLISHER="CN=..."` (субъект сертификата). Другой путь к ROM: `-DRR_UWP_ROM=...`.

## На Xbox
Подходит любой способ:
- **Из Visual Studio:** цель отладки «Удалённый компьютер», IP-адрес Xbox (его показывает Dev Home), проверка подлинности «Universal (Unencrypted Protocol)»; сопряжение по PIN, который показывает Dev Home.
- **Пакетом через Device Portal:** в Visual Studio Проект → Опубликовать → Создать пакеты приложения → Загрузка неопубликованных приложений, x64; затем в браузере на ПК откройте `https://<ip xbox>:11443` (Device Portal, включается в Dev Home), Add и выберите `.msix` вместе с зависимостями из его папки (пакет VCLibs).

Потом в Dev Home выберите приложение, View details и поставьте App type = **Game**: иначе приложению достаётся меньше ресурсов консоли.

## Управление на Xbox
| Геймпад | |
|---|---|
| Крестовина или левый стик | джойстик |
| A, B, Y или правый триггер | огонь |
| X | клавиша паузы (у Xbox нет клавиатуры) |
| Menu | START |
| View | SELECT |
| RB / LB | сохранить состояние / вернуться к нему |

Цвета, палитра, рамка и масштабирование — по умолчанию (цвета PAL, Altirra, только картинка игры, чёткое). B — это ещё и системная кнопка «Назад»; игра её перехватывает, так что приложение не закрывается. Кнопка Xbox выходит из игры.

## Что может понадобиться доделать
- Безопасная зона телевизора: приложения UWP на Xbox могут рисоваться с отступом от краёв экрана. Картинка и так окружена чёрным; если отступ мешает, приложение может попросить весь экран (`ApplicationView::SetDesiredBoundsMode`).
- Как собраны файлы (`uwp/uwp.cmake`, `uwp/Package.appxmanifest.in`): поддержка проектов UWP в CMake и точка входа WinRT из SDL2 (`SDL_winrt_main_NonXAML.cpp`, компилируется как C++/CX) использованы по документации, но здесь не собирались.
