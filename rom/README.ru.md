# ROM

Положите сюда свой дамп картриджа River Raid под именем `River_Raid.rom`: 8192 байта, без заголовка CART, загружается в $A000–$BFFF.

ROM в репозиторий не входит, и для сборки он не нужен. Игра и просмотрщик по умолчанию ищут `rom/River_Raid.rom`; другой путь можно передать первым аргументом.
