Ponga aquí su propio volcado del cartucho de River Raid con el nombre `River_Raid.rom`: 8192 bytes, una imagen en bruto sin cabecera CART, cargada en $A000–$BFFF.

La ROM no forma parte de este repositorio y no hace falta para compilar. El juego y el visor buscan `rom/River_Raid.rom` por defecto; se puede indicar otra ruta como primer argumento.
