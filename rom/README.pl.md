# ROM

Umieść tu własny zrzut kartridża River Raid pod nazwą `River_Raid.rom`: 8192 bajty, surowy obraz bez nagłówka CART, ładowany pod $A000–$BFFF.

ROM nie jest częścią tego repozytorium i nie jest potrzebny do kompilacji. Gra i przeglądarka domyślnie szukają `rom/River_Raid.rom`; inną ścieżkę można podać jako pierwszy argument.
