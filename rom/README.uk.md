# ROM

Покладіть сюди свій дамп картриджа River Raid під назвою `River_Raid.rom`: 8192 байти, без заголовка CART, завантажується в $A000–$BFFF.

ROM до репозиторію не входить, і для збирання він не потрібен. Гра й переглядач за замовчуванням шукають `rom/River_Raid.rom`; інший шлях можна передати першим аргументом.
