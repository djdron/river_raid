Put your own dump of the River Raid cartridge here as `River_Raid.rom`: 8192 bytes, a raw image without a CART header, loaded at $A000–$BFFF.

The ROM is not part of this repository, and the build does not need it. The game and the viewer look for `rom/River_Raid.rom` by default; another path can be given as the first argument.
