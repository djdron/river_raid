# rr_oracle — эталонный прогон River Raid

[English](README.md) | Русский

Headless-прогон оригинального картриджа на libatari800 (Atari 800, NTSC по умолчанию, встроенная AltirraOS, BASIC выключен). Нужен, чтобы покадрово сверять с ним C++-порт.

## Сборка
```
./build.sh
```
Скрипт клонирует atari800 (проверенный коммит 98cc2dc), собирает `libatari800.a` и линкует `rr_oracle`. Нужны git, gcc, make, autoconf и automake (Linux, WSL или MSYS2).

## Запуск
```
./rr_oracle <rom> <script> <frames> <outdir> [-pal] [-seed N] [-bot] [-shot N,N,...]
./rr_oracle ../rom/River_Raid.rom scripts/start_and_fly.txt 1000 out -shot 240,500
./rr_oracle ../rom/River_Raid.rom scripts/start_only.txt 8000 out -bot      # бот
./rr_oracle ../rom/River_Raid.rom scripts/bot_run_8000.txt 8000 out         # повтор прогона бота
```

## Бот (`-bot`)
Сначала проигрывается сценарий (например, `start_only.txt`: включение, START, ожидание), потом управление берёт автопилот. Он рулит к середине воды впереди самолёта, уклоняется от объектов рядом, всё время стреляет, а во время взрыва и ожидания у моста жмёт «вверх». Бот простой и рассчитан только на длинные трассы, не на рекорды: он не ищет топливо и гибнет от вертолётов, выезжающих сбоку.

Применённый ввод любого прогона пишется в `inputs.txt` в формате сценария. Его можно подать обратно без `-bot`, и трасса совпадёт побайтно (проверено на 8000 кадрах).

## Сценарии
| Файл | Что |
|---|---|
| `start_and_fly.txt` | START, разгон, повороты, стрельба (1000 кадров) |
| `attract_fire_only.txt` | огонь в заставке (игра не стартует) |
| `start_only.txt` | включение, START, ожидание; для `-bot` |
| `probe_lr.txt`, `probe_hold.txt` | короткие нажатия / удержание для поиска переменных |
| `bot_run_8000.txt` | записанный прогон бота: 2 моста, 5 гибелей, конец игры, новый старт |

## Сценарий ввода
Каждая строка: `<кадров> <джойстик> <огонь> [start]`, `#` начинает комментарий. Последняя строка повторяется до конца прогона.
Джойстик задаётся битами: 1 вверх, 2 вниз, 4 влево, 8 вправо, 0 означает центр.
Игра стартует клавишей START, огонь из заставки игру не запускает.

## Что пишется в `<outdir>`
| Файл | Содержимое |
|---|---|
| `ram.bin` | $0000–$3FFF (16 КБ) после каждого кадра; кадр N лежит по смещению N*16384 |
| `pokey.log` | каждая запись в POKEY: `кадр строка такт регистр значение` |
| `random.log` | каждое чтение RANDOM: `кадр строка такт значение`. Строка ~249 даёт звук (VBI), остальные строки дают игровую логику (A205) |
| `frames.csv` | применённый ввод и регистры CPU на конец кадра |
| `inputs.txt` | применённый ввод в формате сценария (для повтора) |
| `fNNNNN.ppm` | скриншоты 384×240 |

## Детерминизм
Сам atari800 засевает генератор POKEY от системного времени, поэтому прогоны не повторяются. `rr_oracle` выставляет счётчик явно (`-seed`, по умолчанию 0). При одинаковых ROM, сценарии и сиде все файлы совпадают побайтно (проверено).

Лицензия: libatari800 распространяется под GPL-2.0+, значит и `rr_oracle` как связанная с ней программа тоже. Это инструмент разработки: C++-порт с ним не линкуется и только читает его выходные файлы.
