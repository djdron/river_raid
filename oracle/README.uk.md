# rr_oracle — еталонний прогін River Raid

[English](README.md) | [Русский](README.ru.md) | Українська | [Deutsch](README.de.md) | [Polski](README.pl.md) | [Italiano](README.it.md) | [Español](README.es.md) | [中文](README.zh.md) | [日本語](README.ja.md)

Запускає оригінальний картридж без вікна на libatari800 (Atari 800, типово NTSC, вбудована AltirraOS, BASIC вимкнено). Служить для покадрового порівняння порту на C++ з оригіналом.

## Збирання
```
./build.sh
```
Скрипт клонує atari800 (перевірений коміт 98cc2dc), збирає `libatari800.a` і лінкує `rr_oracle`. Потрібні git, компілятор C (gcc або clang), make, autoconf і automake; працює під Linux, macOS (Xcode command line tools, `brew install autoconf automake`), WSL і MSYS2. Еталон перехоплює три функції емулятора (запис у POKEY, читання RANDOM, NMI зворотного ходу): скрипт ще раз компілює `pokey.c` і `cpu.c` з перейменованими функціями, тож жодних трюків лінкера не потрібно.

## Запуск
```
./rr_oracle <rom> <script> <frames> <outdir> [-pal] [-seed N] [-bot|-bot-nofire] [-ghost] [-noram] [-ram A:B] [-strip Y] [-screens A:B] [-shot N,N,...]
./rr_oracle ../rom/River_Raid.rom scripts/start_and_fly.txt 1000 out -shot 240,500
./rr_oracle ../rom/River_Raid.rom scripts/start_only.txt 8000 out -bot      # bot
./rr_oracle ../rom/River_Raid.rom scripts/bot_run_8000.txt 8000 out         # replay of a bot run
```

## Бот (`-bot`)
Спочатку грає сценарій (наприклад, `start_only.txt`: увімкнення, START, очікування), потім керування бере автопілот. Він кермує до середини води попереду, ухиляється від близьких об'єктів, весь час стріляє й тисне «вгору», поки вибухає або чекає біля мосту. Бот простий і призначений лише для довгих трас, а не для рекордів: він не шукає пальне й гине від гелікоптерів, що заходять збоку.

`-bot-nofire`: той самий автопілот без стрільби й ухилянь.

Натискання, фактично застосовані в будь-якому прогоні, записуються в `inputs.txt` у форматі сценарію. Якщо подати їх назад без `-bot`, траса виходить побайтно ідентичною (перевірено на 8000 кадрах).

## Параметри для зйомки рівня
- `-ghost` — невразливий літак (латка коду на 5 байтів в емульованій пам'яті, лише для зйомки).
- `-strip Y` — рядок екрана Y кожного кадру в `strip.bin`, палітра в `palette.bin`.
- `-screens A:B` — повні екрани кадрів A…B у `screens.bin`.
- `-noram` — не писати `ram.bin` (для довгих прогонів).
- `-ram A:B` — писати `ram.bin` лише для кадрів A…B (кадр A за зсувом 0).
- `-wav` — звуковий вихід емулятора в `sound.wav`.
- `-vbi` — `vbi.bin`: RAM на початку кожного переривання зворотного ходу (записи з 4 байтів номера кадру + 16 384 байтів), стан, який бачить звуковий драйвер.
- `frames.csv` має стовпці `$60, $2F, $5D, $AA, $AB, $AC, $76, $52, $53, $54, $2D, $4E`.

## Сценарії
| Файл | Що |
|---|---|
| `start_and_fly.txt` | START, розгін, повороти, стрільба (1000 кадрів) |
| `attract_fire_only.txt` | вогонь на титульному екрані (гра не починається) |
| `start_only.txt` | увімкнення, START, очікування; для `-bot` |
| `probe_lr.txt`, `probe_hold.txt` | короткі натискання / утримання для пошуку змінних |
| `bot_run_8000.txt` | записаний прогін бота: 2 мости, 5 загибелей, кінець гри, новий старт |
| `refuel_first_depot.txt` | проліт над першою заправкою без стрільби (заправлення) |
| `attract_idle.txt` | увімкнення й жодних натискань: демонстраційний режим (річка гри 1, титри, що біжать) |
| `two_players.txt` | SELECT на гру 2, START; обидва гравці летять прямо й стріляють, доки не втратять усі літаки; клавіша паузи двічі |
| `ghost_film.txt` | старт і політ без натискань; з `-ghost -noram -strip 20` знімає карту рівня |

## Сценарій введення
Кожен рядок: `<кадри> <джойстик> <вогонь> [start] [select] [option] [джойстик2] [вогонь2] [клавіша]`; `#` починає коментар. Останній рядок повторюється до кінця прогону. `клавіша` тримає пробіл (будь-яка клавіша ставить River Raid на паузу).
Біти джойстика: 1 угору, 2 униз, 4 ліворуч, 8 праворуч, 0 по центру.
Гра починається клавішею START; вогонь на титульному екрані її не запускає.

## Що потрапляє в `<outdir>`
| Файл | Вміст |
|---|---|
| `ram.bin` | $0000–$3FFF (16 КБ) після кожного кадру; кадр N за зсувом N*16384 |
| `pokey.log` | кожен запис у POKEY: `кадр рядок_розгортки такт регістр значення` |
| `random.log` | кожне читання RANDOM: `кадр рядок_розгортки такт значення`. Рядок ~249 — звук (VBI), інші рядки — логіка гри (A205) |
| `frames.csv` | застосовані натискання (джойстик, вогонь, START, потім після стовпців процесора SELECT, OPTION, джойстик 2, вогонь 2, клавіша) і регістри процесора наприкінці кадру |
| `inputs.txt` | застосовані натискання у форматі сценарію (для повтору) |
| `fNNNNN.ppm` | знімки екрана 384×240 |

## Детермінованість
Сам atari800 запускає генератор POKEY від системного годинника, тому прогони не повторюються. `rr_oracle` задає лічильник явно (`-seed`, типово 0). З тим самим ROM, сценарієм і зерном усі файли побайтно ідентичні (перевірено).

Ліцензія: libatari800 — GPL-2.0+, тож `rr_oracle` як програма, злінкована з нею, теж. Це інструмент розробки: порт на C++ з нею не лінкується й лише читає її вихідні файли.
